<product_requirements>
The user requires a highly advanced, spreadsheet-based Interior Design Project Management App. It needs to handle a workflow from Questionnaire to Walkthrough, Checklist, and finally FFE (Furniture, Fixtures, and Equipment). Information must flow seamlessly between these sheets. Key integrations include Houzz Pro, Microsoft Teams, My Measures, Canva, and potentially a Leica D5 laser pointer for measurements. The application must support web scraping, shipping tracking, date selection, pie charts for status, and inventory tracking.

Specific features include:
1.  **Questionnaire**: Email to customer, beautiful customer-facing interface for data input.
2.  **Designer Landing Page**: Automatically populated with questionnaire answers.
3.  **Contact Sheet**: Manages client, builder, architect, receiver, and other contacts.
4.  **Walkthrough Sheet**: Mobile app interface, offline capability, pre-loaded rooms/items from questionnaire with checkboxes, dynamic editing (add/delete/rearrange rooms/items/categories), picture/measurement taking (including Leica integration), and transfer to Checklist.
5.  **Checklist**: Curation phase. Add item pop-up with web scraping for product details (name, size, color, link, image, SKU, cost). Status dropdown linked to pie chart for presentation readiness. Integrates with Microsoft Teams for to-do tasks. Ability to populate Canva boards with links and transfer actual items to FFE.
6.  **FFE (Bible for Designers)**: Offline capability, app interface, picture/measurement taking for onsite changes, live shipping tracking, status dropdowns for install readiness, order date cells.
7.  **New Feature Request (Calculators)**: Wallpaper, Drapery, Drapery Hardware, and Square Footage calculators. The square footage calculator should potentially integrate with Leica measurements from pictures. The calculators need to be separate but in the same section, specifically added to the right container on the Checklist page (replacing shipping info) and as a tab within each project's detail page. The UI color for new features should be muted gold, matching the app's theme, not in your face.
8.  **Power Features**: AI Room Type Detection, Smart Shopping List Generator, Budget Tracker, Vendor Contact Manager, Material Library, Installation Cost Estimator, Before/After Photo Comparisons (requested after initial calculator discussion).
</product_requirements>

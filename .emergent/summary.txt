<product_requirements>
The application is a comprehensive Interior Design Project Management tool designed to streamline the workflow from client onboarding to project completion.

The core data flow begins with a **Customer-facing Questionnaire**, which, upon submission, automatically populates a project, creates contacts for the project team (Client, Spouse, Architect, Builder, etc.), and sets up rooms for a **Mobile Walkthrough**.

During the walkthrough, the designer uses a mobile-optimized web app to select (PICK) items for each room. These picked items then appear on a **Checklist** for curation and on a master **FF&E (Furniture, Fixtures & Equipment)** spreadsheet for tracking procurement. The application includes eight specialized **Calculators** (e.g., wallpaper, drapery, paint) for quick estimates.

A newly implemented **Critical Path** dashboard provides a centralized view of all ordered items from various vendors (Four Hands, Uttermost, Visual Comfort, etc.), syncing tracking information directly with the FF&E sheet.

The long-term vision includes a **Dimensional Mood Board**, an advanced tool for 3D room visualization, AI-powered photorealistic rendering, and LiDAR integration for creating accurate floor plans. The app is intended to be accessed via a custom subdomain ().
</product_requirements>
